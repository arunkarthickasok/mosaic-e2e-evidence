Motion spec12 · CHOREOGRAPHY
← UI kit

Motion only confirms cause and effect: where something came from, where it went, and whether the server has caught up. Nothing overshoots or springs, and nothing loops except the stale shimmer. Under prefers-reduced-motion, every duration token goes to 0 and each moment is shown by a static state change instead.

Reduced motion is on. Each cell shows the end state it snaps to; the "Reduced" line says what replaces the movement.
